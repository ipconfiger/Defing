# 03 结构配置与共享引用

结构定义了一个项目**有哪些配置项**：分组 → 配置项（key、类型、必填、敏感、共享引用）。**发布结构后对所有分支同时生效**，各分支再填不同的值。

## 3.1 结构页

项目内切到「结构」页签：

![结构页]({{ site.baseurl }}/assets/images/04-structure.png)

## 3.2 分组与配置项

1. 「添加组」创建分组（如 `redis`）
2. 组内「添加配置项」：填写 key、选类型、勾选 required / secret
3. 「保存草稿」→「发布结构」

支持的类型：

| 类型 | 说明 | 渲染 / 值示例 |
|---|---|---|
| `string` | 字符串 | `host: 10.0.0.1` |
| `int` | 整数 | `port: 6379` |
| `float` | 浮点数 | `ratio: 0.5` |
| `bool` | 布尔 | `verbose: true` |
| `json` | JSON 文本 | `healthcheck: {"path": "/healthz"}` |
| `array` | 字符串数组（逗号分隔） | `tags: a, b, c` |
| `secret` | 敏感项（加密存储，数据面恒脱敏 `***`） | 需要主密钥 |

- **required**：发布前该配置项必须有值，否则发布被拦截（校验策略可改为 `warn` 仅警告）
- **secret**：值加密存储；数据面 / 渲染输出恒为 `***`，仅管理面 `reveal=true` 且审计后才解密

## 3.3 共享引用

配置项可以引用**共享库**中的共享项（详见 [06 共享库]({{ site.baseurl }}/06-shared/)）：

1. 先在「共享库」创建并发布共享项（如 `timeout`）
2. 结构编辑器里给配置项选「共享引用」下拉 → 选择共享项
3. 发布结构后，该配置项在草稿页**只读**，值由共享库物化（共享项更新发布后自动级联）

草稿页中引用项显示「引用共享」徽章且不可编辑：

![草稿页引用共享]({{ site.baseurl }}/assets/images/03-draft.png)

> 引用项的类型 / 必填 / 敏感属性继承共享项定义；被引用的共享项不可直接删除（需先移除引用）。

## 3.4 结构版本与编辑

- 结构编辑器显示「基于 svN」：保存草稿时 `base_version` 必须等于当前已发布结构版本
- 其他管理员发布了新结构后，本页会出现「结构已更新」提示，点「载入当前」重新加载再编辑
- 「发布结构」会推进**全部分支**的版本；结构中已删除的配置项，其未发布草稿值会被自动清理
