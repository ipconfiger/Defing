# 06 共享库

共享库存放**跨项目复用的配置项**（扁平 key，无分组）。项目结构通过「共享引用」绑定共享项后，值由共享库物化 —— 共享项更新发布，引用它的所有项目分支**自动级联**。

## 6.1 共享库页面

左侧导航「共享库」：

![共享库]({{ site.baseurl }}/assets/images/09-shared.png)

上方表单创建 / 更新共享项，下方列表展示全部共享项（含草稿与已发布状态、被引用处数）。

## 6.2 创建并发布共享项

1. 填 key（全局唯一，如 `timeout`）、类型、描述、值
2. 点「保存共享草稿」（写入 `shared-draft`）
3. 点「发布共享」→ 发布全部草稿，引用它的项目分支自动级联生成新版本

列表中的行标识：

| 标识 | 含义 |
|---|---|
| `草稿`（橙） | 已保存但未发布，尚未生效 |
| `v1`（绿） | 已发布版本 |
| `N 处`（蓝） | 被多少个项目的结构引用 |
| 表单未保存 / N 个共享草稿未发布 | 顶部状态徽章：有多少没保存、多少存了没发 |

## 6.3 项目引用共享项

在项目「结构」页给配置项选「共享引用」→ 共享项：

![草稿页引用共享]({{ site.baseurl }}/assets/images/03-draft.png)

- 引用项在草稿页**只读**，显示「引用共享」徽章与物化值
- 共享项 `timeout` 发布 v2 后，所有引用它的项目分支自动产生 shared_cascade 版本
- 删除共享项时若仍被引用会被拒绝（需先移除各项目中的引用）

## 6.4 共享项类型与 secret

- 支持与配置项相同的类型（string / int / float / bool / json / array / secret）
- **secret 共享项**需要主密钥；数据面恒脱敏（`***`）
- 描述字段（≤200 字节）仅作助记，不进入渲染输出
