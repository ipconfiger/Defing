## 4. 每模块 Definition of Done
1. 模块规格任务清单全勾选；2. 对应用例 ID 测试全绿；3. 文档注释完整；
4. 无 clippy warning；5. 错误映射正确（05 表）；6. 指标/审计埋点到位。

## 5. 里程碑验收清单

- **M1 验收**：`dsh --dev-single` 起单节点 → 建项目/分支 → 改草稿 → 发布 → GetConfig 读到新版本；
  3 节点（bootstrap+join+join）→ kill 任一节点读写不中断；watch 收到发布事件。
- **M2 验收**：幂等重复发布只生效一次；回滚后版本历史完整；结构发布全分支推进；
  共享库发布自动级联；磁盘扫描无明文；YAML/TOML/JSON 等价。
- **M2.5 验收**：Admin UI 全流程（登录→改草稿→发布→回滚）；第二个登录被拒（I7）；
  指标/审计可查；健康检查正确。
- **M3 验收**：三语言 SDK 契约测试对拍全绿。
- **M4 验收**：混沌测试通过；基准达标（写 QPS ≥10k、watch ≥10k、发布→SDK ≤1s、
  内存 ≤128MB、二进制 ≤50MB）；发布清单（镜像/SBOM/compose）就绪。

## 6. 风险与回退

| 风险 | 应对 |
|------|------|
| openraft trait 与文档不一致 | M1 第 1 周固定版本并写最小 demo（模块 03 任务 1） |
| rust-rocksdb 构建/链接问题 | 备选：librocksdb-sys 版本固定；CI 缓存构建产物 |
| 三语言 SDK 时间超支 | M3 优先 Go + Python（服务端主流），TS 浏览器版后置 |
| 版本存储增长 | checkpoint + 裁剪（模块 11）提前到 M2 初 |
| 单会话卡死 | 会话清扫（模块 11）+ CLI force-logout（M1 即实现） |
