# 02 项目与分支

配置按 **项目 → 分支** 组织：一个项目对应一个应用 / 服务，分支对应环境（dev / test / prod / 自定义）。

## 2.1 新建项目

登录后首页点击「新建项目」，输入项目名（小写字母 / 数字 / 连字符）：

![配置管理首页]({{ site.baseurl }}/assets/images/02-home.png)

项目创建后**自动带 dev / test / prod 三个分支**。

## 2.2 切换项目与分支

顶部上下文栏：

- 项目：点项目名（chip）切换；当前项目高亮
- 分支：下拉选择分支，切换后草稿 / 版本 / 灰度等页签全部跟随该分支

![配置管理首页]({{ site.baseurl }}/assets/images/02-home.png)

分支选择旁显示当前状态徽章：

| 徽章 | 含义 |
|---|---|
| 稳定版 v2 | 当前活动版本号 |
| 结构 sv2 | 已发布结构版本 |
| 灰度 #1 | 当前分支有灰度进行中（序号） |

## 2.3 新建 / 删除分支

上下文栏「新建分支」：输入分支名（可指定从某个分支复制初始草稿值）。

「删除分支」（垃圾桶按钮）：删除该分支的全部草稿与版本历史（不影响其他分支）。

## 2.4 分支间值提升（Promote）

「对比与提升」页签可以把一个分支的活动版本值写入另一分支的草稿：

1. 选择源分支与目标分支
2. 勾选 force 可覆盖目标分支已修改的草稿
3. 「提升」后目标分支草稿更新（不自动发布）

> 结构（有哪些配置项）是项目级**强一致**的，分支之间只存在**值**的差异 —— 这就是切换环境只是换分支名的原因。
